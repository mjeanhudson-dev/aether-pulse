# Aether Pulse — Local Desktop Liquid-Physics Overlay (`v1.0.3`)

Authored by **Eloquent** (`@mjeanhudson-dev`)

A frameless, topmost Cupertino-styled desktop HUD that floats over any AI terminal, browser, or IDE (`Claude Code`, `Google Antigravity`, `OpenAI Codex CLI`, `Cursor`, `Aider`, `Windsurf`, `Continue.dev`, `GitHub Copilot`, `OpenHands`, `T3 Code`, `Windows Terminal`, `Chrome`):

1. **Native Win32 Rounded Corners & Stadium Canvas:**
   - Frameless OS window clipped via `CreateRoundRectRgn` / `SetWindowRgn` for native anti-aliased rounded corners.
2. **Dedicated Light & Dark Theme Switcher (`[ ☀️ LGT ]` / `[ 🌙 DRK ]`):**
   - Click the middle button on the right control column to toggle between Dark Obsidian and Crisp Cupertino Light palettes.
3. **Top 10 Harness Detection & Mesh:**
   - Detects all 10 major agent harnesses across Google Search & GitHub: Claude Code, Google Antigravity, OpenAI Codex CLI, Cursor, Aider, Windsurf, Continue.dev, GitHub Copilot, OpenHands, and Ping T3 Code.
   - Cycle through harnesses or view all simultaneously in the comparative 2-column drawer.
4. **High-Fidelity 48-Node Fluid Dynamics & Wall Splashes:**
   - 48 spring nodes provide fluid wave simulation.
   - Wall impacts excite violent directional surges along the impact flank and spawn dynamic droplet particles that spray and fall under gravity.
5. **Unnatural Viscous High-Speed Braking:**
   - When thrown or flung across your desktop at high velocity (>180 px/s), non-linear eddy viscosity damping arrests the runaway momentum, settling into a smooth glide.
6. **Switchable Boundary Physics (`[ BNC ]` / `[ PAC ]` / `[ PIN ]`):**
   - **`BNC` (Bounce Walls):** Bounces elastically off monitor edges with wave crash surges and splash droplets.
   - **`PAC` (Pac-Man Wrap):** Flies through bottom-to-top and side-to-side screen edges toroidally.
   - **`PIN` (Pin Anchor):** Settles at the release coordinate with micro-buoyancy.
7. **Elevated & Diversified Typography:**
   - `Segoe UI Variable Display` micro-caps header, `Cascadia Code` / `Consolas` tabular figures, and clean secondary metrics.

## Quick Start (Windows / macOS / Linux)

- **1-Click Windows Launch:** Double-click `Launch-Aether-Overlay.bat` or `aether_liquid_overlay.pyw`.
- **CLI Launch:**
  ```powershell
  python aether_pulse_ws.py
  python aether_liquid_overlay.py
  ```
