# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Developers running multiple AI coding harnesses (Claude Code, Google Antigravity, OpenAI Codex CLI) who want to see their usage and compare efficiency with friends and cohorts.

## Product Purpose
Aether Pulse shifts AI-coding benchmarks from raw uncached API spend to engineering leverage per dollar. It unifies local session telemetry across the three harnesses and ranks operators by a 3-Pillar Leverage Index (cache mastery, multi-model routing discipline, proof-of-work). Success: better coders compete to use AI more efficiently.

## Positioning
Ranks efficiency (cache hit rate, leverage per dollar) rather than spend, across multiple harnesses, with a floating liquid-physics HUD that follows whichever harness window is underneath. Also intended as an open-source, drop-in API/plugin any harness can adopt, in contrast to terminal-only counters (tokscale) and spend-ranked boards (viberank).

## Operating Context
Local-first scanning of on-disk harness logs; localhost WebSocket on 127.0.0.1:8765 feeding a desktop overlay, Chrome extension, and dashboard; MCP server; optional Cloudflare Worker + D1 edge leaderboard.

## Capabilities and Constraints
- Public identity is always "Eloquent" (@mjeanhudson-dev); no OS username or local paths in public artifacts.
- Local-first; no secrets or keys uploaded.
- Budget / $0 hosting tier.
- Public leaderboard is explicitly undecided and not built yet; reward/feature program for efficient users is undecided.

## Evidence on Hand
Real local telemetry from the three harnesses; T3 Code usage-board screenshots used as design reference. No external testimonials or user counts exist; do not fabricate.

## Product Principles
1. Reward efficiency, not burn.
2. Local-first and privacy-preserving.
3. Harness-agnostic and plug-in simple.
4. Verifiable numbers (proof-of-burn, entropy anti-cheat).
