Prompt-Cache Alignment & The 90% Economics Rule

Modern frontier LLMs (Gemini 3.8 / 4 Argon, Claude Opus 5.5, OpenAI Codex) employ prompt prefix caching. When the leading tokens of your prompt (system rules, tool schemas, repository index) match previous turns byte-for-byte, compute providers grant a 75% to 90% discount and deliver sub-second time-to-first-token (TTFT).

💡 Golden AI Usage Practices

  • Pin Immutable System Prompts: Place behavioral rules (like AGENTS.md or CLAUDE.md) at the very front of the session.
  • Zero Prefix Churn: Never inject variable timestamps, random seeds, or dynamic turn counters into the system prefix.
  • Deterministic Tool Ordering: Order MCP tools and skill registrations alphabetically so schemas don't bust the cache.
